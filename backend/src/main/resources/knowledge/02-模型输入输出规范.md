# 模型输入输出规范

本页说明每一类模型的输入要求与输出结构。字段要求以平台数据库中的
「模型输入规范」为准，本文档用于解释「为什么这样要求」。

## 通用文件限制

图像类模型的上传限制：

- 单文件不超过 **5MB**；
- 支持格式：JPG、PNG、WEBP、GIF、BMP；
- 超过大小或格式不符时，接口返回 400 并说明原因，不会进入推理。

文本类模型的输入限制：

- 单次文本建议不超过 2000 字符；
- 空文本会被拒绝（返回 400「text 不能为空」）；
- 超长文本请截断或分段，逐段调用。

## 图像分类模型（ResNet-50 / FlowerCNN / ChestCT）

输入：一张图片。
输出：

- `topLabel`：置信度最高的类别名；
- `confidence`：该类别置信度（0~1）；
- `candidates`：Top-5 候选类别及各自置信度。

说明：ResNet-50 基于 ImageNet 的 1000 类日常物体训练，**不适合**医学影像；
ChestCT 才是胸部 CT 专用模型。用错模型时结果往往表现为「置信度很低、候选类别互不相关」。

## 目标检测模型（YOLOv8）

输入：一张图片。
输出：检测到的目标列表，每项包含类别、置信度与边界框坐标。

说明：目标检测返回的是「多个目标」，不是「整张图属于哪一类」。
如果只需要整体分类，用图像分类模型即可，检测模型的开销更大。

## 图像分割模型（U2Net）

输入：一张图片。
输出：`resultType=image_processing` 与结果图（Base64）。用于抠图、去背景。

说明：这类模型的返回体里没有 `topLabel` 意义上的「类别」，
前端展示的是处理后的图片，不要当成分类结果解读。

## 文本情感模型（BERT-Base / ChineseSentiment）

输入：一段文本。
输出：`topLabel` 为情感标签（如 POSITIVE / NEGATIVE），`confidence` 为置信度，附候选列表。

说明：英文模型与中文模型不可互换。用英文模型分析中文文本时，
分词结果会大量落到未知词，置信度通常异常且不可解释。

## 结构化预测模型（XGBoost / WeatherGBM / StockRegression）

输入：一个 JSON 对象，字段名必须与模型要求完全一致（大小写敏感者有之）。
示例（XGBoost 鸢尾花）：
`{"sepal_length":5.1,"sepal_width":3.5,"petal_length":1.4,"petal_width":0.2}`

输出：预测类别或预测值，附候选概率。

说明：

- 缺字段会直接报错，列出缺失项；不会用默认值代替。
- 字段值必须是数字，字符串形式的数字（如 "5.1"）会被尝试转换，无法转换则报错。
- 不同模型的字段集合不同，调用前务必查该模型的输入规范。
